> 연구비 집행 등록부터 영수증 OCR, 법령 기반 AI 감사, 소명 제출, 보완 요청, 최종 승인까지 이어지는 업무형 웹 포트폴리오 프로젝트입니다.

## 1. 프로젝트 소개

CaaS는 연구비 집행 과정에서 반복적으로 발생하는 증빙 검토, 규정 확인, 소명 요청, 승인 처리 업무를 하나의 웹 흐름으로 묶은 감사 지원 서비스입니다.

일반적인 정산 시스템은 사용자가 비용을 등록하고 관리자가 목록을 확인하는 수준에 머무르는 경우가 많습니다. CaaS는 여기에 AI를 붙여 다음 과정을 자동화하거나 보조합니다.

- 영수증 이미지에서 금액, 날짜, 품목, 영수증 번호를 추출
- 집행 내용과 관련 있는 연구비 규정/법령을 매칭
- AI가 정상/검토필요 여부와 근거 코멘트를 생성
- 검토필요 항목에 대해 소명서 초안을 생성
- 감사자와 관리자가 보완 요청 및 최종 승인을 처리

이 프로젝트의 목적은 **AI가 단순히 문장을 생성하는 기능을 넘어, 실제 업무 의사결정 흐름 안에서 근거 기반 감사 보조 역할을 수행하는 웹 서비스**를 구현하는 것입니다.

## 3. 핵심 문제 정의

연구비 정산/감사 업무에서는 다음 문제가 반복됩니다.

| 문제 | CaaS의 접근 |
|---|---|
| 영수증 내용을 사람이 직접 입력해야 함 | AI OCR로 금액, 날짜, 품목, 영수증 번호 자동 추출 |
| 규정 확인이 수동적이고 시간이 오래 걸림 | 집행 내용과 관련 규정을 매칭해 AI 판단 근거로 사용 |
| 검토필요 항목의 소명 작성이 번거로움 | AI가 소명서 초안을 생성하고 사용자가 보완 |
| 역할별 업무가 섞여 화면이 복잡해짐 | 연구원, 감사자, 관리자 권한에 따라 메뉴와 액션 분리 |
| 승인/보완 요청 결과가 명확히 남지 않음 | 상태 전환과 완료 메시지로 업무 흐름을 명확히 표시 |

## 4. 주요 기능

### 역할별 진입 및 권한 분리

첫 화면에서 연구원, 감사자, 관리자 역할로 진입합니다. 선택한 역할에 따라 사이드바 메뉴와 사용 가능한 액션이 달라집니다.

| 역할 | 주요 목적 | 대표 기능 |
|---|---|---|
| 연구원 | 집행 등록, 감사 결과 확인, 소명 제출 | 영수증 등록, 정산 현황 확인, 소명서 작성 |
| 감사자 | 집행 항목 검토, 보완 요청, 승인 판단 | 검토필요 항목 확인, 보완 요청, 패턴 탐지 |
| 관리자 | 전체 운영, 규정/조직 관리, 최종 승인 | 규정 관리, 조직 관리, 전체 현황 확인 |

### AI 영수증 자동등록

영수증 이미지를 업로드하면 Gemini 기반 OCR 분석을 통해 입력 폼을 자동 보완합니다.

- 판매처
- 날짜
- 금액
- 품목
- 추천 분류
- 영수증 번호/거래번호/승인번호

### 법령 기반 AI 감사

사용자가 등록한 집행 내용과 카테고리를 기준으로 관련 규정 데이터를 찾아 AI 감사 프롬프트에 포함합니다. AI는 해당 규정을 근거로 감사 점수, 상태, 코멘트를 생성합니다.

### AI 소명서 초안 생성

검토필요 항목에 대해 연구원이 소명서를 작성할 때, AI가 집행 목적과 감사 코멘트를 반영한 초안을 생성합니다. 사용자는 이 초안을 수정해 제출할 수 있습니다.

### 보완 요청 및 최종 승인

감사자는 검토 결과에 따라 보완 요청을 보낼 수 있습니다. 연구원이 소명을 제출하면 감사자는 해당 제출분을 재검토하고, 최종 승인으로 이어집니다.

## 5. 업무 흐름

### 기본 처리 흐름

```text
증빙 등록 -> OCR/RAG 처리 -> AI 감사 판정 -> 감사 검토 -> 최종 승인
```

### 보완 필요 시

```text
감사 검토 -> 보완 요청 -> 소명 제출 -> 재검토 -> 최종 승인
```

보완 요청은 감사 검토의 결과이며, 연구원이 소명을 제출한 뒤 해당 제출분을 다시 검토하는 구조입니다.

## 6. AI 적용 방식

### OCR

영수증 이미지를 분석해 정산 입력에 필요한 구조화 데이터를 추출합니다.

### RAG

RAG는 Retrieval-Augmented Generation의 약자입니다. CaaS에서는 사용자가 등록한 집행 내용과 관련 있는 규정/법령 데이터를 먼저 찾고, 그 내용을 AI 감사 판단의 근거 컨텍스트로 사용합니다.

즉, CaaS의 RAG는 **AI가 임의로 판단하는 것이 아니라 관련 규정 근거를 참고해 감사 코멘트를 생성하도록 돕는 구조**입니다.

### 감사 판정

AI는 영수증 정보, 집행 설명, 금액, 카테고리, 관련 규정 컨텍스트를 함께 보고 다음 결과를 생성합니다.

- 감사 점수
- 정상/검토필요 상태
- 근거 규정 기반 코멘트
- 소명 필요 여부

### 소명서 생성

AI는 검토필요 항목에 대해 연구 목적, 집행 필요성, 증빙 맥락을 반영한 소명서 초안을 생성합니다.

## 10. 실행 방법

### 요구 사항

- Node.js 18+
- npm 9+

### 설치

```bash
npm install
```

### 환경 변수

루트에 `.env` 파일을 만들고 필요한 값을 설정합니다.

```env
VITE_GEMINI_API_KEY=your_gemini_api_key
```

Firebase 연동을 사용하는 경우 `firebase-applet-config.json`에 Firebase 프로젝트 설정을 구성합니다.

### 개발 서버

```bash
npm run dev
```

기본 주소는 [http://localhost:3000](http://localhost:3000)입니다.

CaaS는 연구비 감사 업무의 흐름을 웹으로 재구성하고, AI OCR과 법령 기반 감사 판단을 결합한 포트폴리오 프로젝트입니다. 단순한 CRUD 화면이 아니라 **역할별 업무 분리, 규정 근거 기반 판단, 소명/보완/승인 흐름**을 실제 화면과 데이터 구조로 구현한 점이 핵심입니다.
